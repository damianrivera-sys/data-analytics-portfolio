# Power BI Dashboard – Business Performance

## Problem
Businesses struggle to track key metrics and make fast decisions due to scattered data.

## Solution
Developed an interactive Power BI dashboard that consolidates key performance indicators such as revenue, costs, and operational metrics into a single view.

## Results
- Improved visibility of business performance
- Faster and more informed decision-making
- Identification of performance trends and inefficiencies

## Tools
Power BI, Data Modeling
